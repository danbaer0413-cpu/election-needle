How to upload (Chrome, github.com):
  1. Unzip this file.
  2. Open your repo's main page. Click Add file > Upload files.
  3. Drag the config folder AND the data folder from the unzipped folder onto the page (drag the folders, not the files).
     GitHub keeps the folder paths and replaces the matching files.
  Also drag civic_results.py, civic_probe.py, auto_calls.py, sources.py, model.py, house_results.py, house_lean.py and
     house_view.py (they all go in the top folder of the repo).
  The .github folder starts with a dot: if you can't see it, turn on hidden items (File Explorer > View > Hidden items).
     Drag it in too.
  4. Check the list shows 16 files with paths like config/races.json and data/NC/u-s-senate/counties.csv.
  5. Commit changes. Then Actions > civic-probe > Run workflow (again, with the fixed probe). When it finishes,
     Actions > update workflow > Run workflow.
Do not upload UPLOAD_STEPS.txt (harmless if you do).
